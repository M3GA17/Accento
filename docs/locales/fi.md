# Accento pikakäynnistys — Suomi

> Tämä käännetty opas on luonnos, eikä äidinkielenään puhuva ole tarkistanut sitä.

Avaa Accento.exe Windowsissa. Asetuskäyttöliittymä on aina pimeä.

Pidä kirjainta painettuna, paina välilyöntiä ja vapauta se ja vapauta sitten kirjain lisätäksesi valitun merkin. Käytä vasenta, oikeaa tai välilyöntiä muuttaaksesi sitä. Pako peruuntuu.

Avaa merkistöjä ja ota käyttöön kielet, joilla kirjoitat. Pidä vähintään yksi sarja aktiivisena. Jaetut merkit näkyvät vain kerran.

Valitse käyttöliittymän kieli Yleistä. Tämä ei muuta aktiivisia merkistöjäsi.

Tallenna muutokset käyttää asetuksiasi. Hylkää muutokset palauttaa viimeksi tallennetun kokoonpanon. Tauko astuu voimaan välittömästi.

Asetusten sulkeminen jättää Accento:n käyntiin ilmoitusalueella. Lopeta se valitsemalla sen valikosta Poistu.

Microsoft Edge WebView2 Runtime vaaditaan. Käyttöliittymä toimii offline-tilassa. Syöttömoottori tukee tällä hetkellä vain Windowsia.

Vakioaakkoset ja käytettävissä olevat näppäinyhdistelmät on lueteltu alla. Kirjoita tavalliset kirjaimet normaalisti. Ponnahdusikkuna tukee myös digrafeja ja merkkien yhdistämistä; se ei korvaa syöttötapaa.
