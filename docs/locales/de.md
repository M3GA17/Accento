# Accento Schnellstart — Deutsch

> Dieser übersetzte Leitfaden ist ein Entwurf und wurde nicht von einem Muttersprachler überprüft.

Öffnen Sie Accento.exe unter Windows. Die Einstellungsoberfläche ist immer dunkel.

Halten Sie einen Buchstaben gedrückt, drücken Sie kurz die Leertaste und lassen Sie dann den Buchstaben los, um das ausgewählte Zeichen einzufügen. Verwenden Sie Links, Rechts oder die Leertaste, um es zu ändern. Escape bricht ab.

Allgemein → Zeichensätze

Öffnen Sie Zeichensätze und aktivieren Sie die Sprachen, in denen Sie schreiben. Lassen Sie mindestens einen Satz aktiv. Gemeinsame Charaktere erscheinen nur einmal.

Wählen Sie unter „Allgemein“ die Sprache der Benutzeroberfläche aus. Dadurch werden Ihre aktiven Zeichensätze nicht verändert.

Änderungen speichern übernimmt Ihre Einstellungen. Durch „Änderungen verwerfen“ wird die zuletzt gespeicherte Konfiguration wiederhergestellt. Die Pause wird sofort wirksam.

Durch das Schließen der Einstellungen wird Accento weiterhin im Benachrichtigungsbereich ausgeführt. Wählen Sie „Beenden“ aus dem Menü, um es zu stoppen.

Microsoft Edge WebView2 Runtime ist erforderlich. Die Schnittstelle funktioniert offline. Die Eingabe-Engine unterstützt derzeit nur Windows.

Das Standardalphabet und die verfügbaren Schlüsselzuordnungen sind unten aufgeführt. Geben Sie normale Buchstaben normal ein. Das Popup unterstützt auch Digraphen und Kombinationszeichen; Es ersetzt keine Eingabemethode.
