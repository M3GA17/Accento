# Accento tús tapa — Gaeilge

> Is dréacht é an treoirleabhar aistrithe seo agus níl aon léirmheas déanta ag cainteoir dúchais air.

Oscail Accento.exe ar Windows. Bíonn an comhéadan socruithe dorcha i gcónaí.

Coinnigh litir, brúigh agus scaoil Spás, ansin scaoil an litir chun an carachtar roghnaithe a chur isteach. Úsáid Clé, Deas nó Spás chun é a athrú. Éalú ar ceal.

Oscail tacair Carachtar agus cumasaigh na teangacha a scríobhann tú iontu. Coinnigh ar a laghad tacar amháin gníomhach. Ní fheictear carachtair chomhroinnte ach uair amháin.

Roghnaigh teanga an chomhéadain i nGinearálta. Ní athraíonn sé seo do thacair carachtar gníomhacha.

Baineann do shocruithe le Sábháil athruithe. Athchóirítear an chumraíocht dheireanach a shábháiltear. Tagann sos i bhfeidhm láithreach.

Fágann socruithe deiridh Accento ag rith sa limistéar fógra. Roghnaigh Scoir óna roghchlár chun é a stopadh.

Tá Microsoft Edge WebView2 Runtime ag teastáil. Oibríonn an comhéadan as líne. Ní thacaíonn an t-inneall ionchuir ach le Windows amháin.

Tá an aibítir chaighdeánach agus na príomhcheangail atá ar fáil liostaithe thíos. Clóscríobh gnáthlitreacha de ghnáth. Tacaíonn an aníos freisin le déghraif agus le marcanna a chomhcheangal; ní chuireann sé ionad modh ionchuir.
