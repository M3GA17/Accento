# Accento avvio rapido — Italiano

> Questa guida tradotta è una bozza e non è stata rivista da un madrelingua.

Apri Accento.exe su Windows. L'interfaccia delle impostazioni è sempre buia.

Tieni premuta una lettera, premi e rilascia Spazio, quindi rilascia la lettera per inserire il carattere selezionato. Usa Sinistra, Destra o Spazio per cambiarlo. La fuga annulla.

Apri i set di caratteri e abilita le lingue in cui scrivi. Mantieni attivo almeno un set. I personaggi condivisi appaiono solo una volta.

Scegli la lingua dell'interfaccia in Generale. Ciò non modifica i set di caratteri attivi.

Salva modifiche applica le tue impostazioni. Annulla modifiche ripristina l'ultima configurazione salvata. La pausa ha effetto immediato.

La chiusura delle impostazioni lascia Accento in esecuzione nell'area di notifica. Scegli Esci dal suo menu per interromperlo.

è richiesto il runtime di Microsoft Edge WebView2. L'interfaccia funziona offline. Il motore di input attualmente supporta solo Windows.

L'alfabeto standard e le associazioni dei tasti disponibili sono elencati di seguito. Digita normalmente le lettere ordinarie. Il popup supporta anche i digrafi e i segni di combinazione; non sostituisce un metodo di input.
