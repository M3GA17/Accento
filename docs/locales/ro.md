# Accento pornire rapidă — Română

> Acest ghid tradus este o schiță și nu a fost revizuit de un vorbitor nativ.

Deschideți Accento.exe pe Windows. Interfața de setări este întotdeauna întunecată.

Țineți apăsată o literă, apăsați și eliberați Space, apoi eliberați litera pentru a introduce caracterul selectat. Folosiți Stânga, Dreapta sau Spațiu pentru a o schimba. Evadarea se anulează.

Generale → Seturi de caractere

Deschideți seturi de caractere și activați limbile în care scrieți. Păstrați cel puțin un set activ. Caracterele partajate apar o singură dată.

Alegeți limba interfeței în general. Acest lucru nu schimbă seturile de caractere active.

Salvarea modificărilor aplică setările dvs. Renunțați la modificări restaurează ultima configurație salvată. Pauza are efect imediat.

Închiderea setărilor lasă Accento rulând în zona de notificare. Alegeți Ieșire din meniul său pentru a o opri.

Microsoft Edge WebView2 Runtime este necesar. Interfața funcționează offline. Motorul de intrare acceptă în prezent numai Windows.
