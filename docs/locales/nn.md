# Kom i gang med Accento — Norsk nynorsk

> Denne omsette rettleiinga er eit utkast og er ikkje gjennomgått av ein morsmålsbrukar.

Opne Accento.exe i Windows. Innstillingane har alltid mørk utsjånad.

Hald ein bokstav nede, trykk og slepp mellomrom, og slepp så bokstaven for å setje inn det valde teiknet. Bruk venstre, høgre eller mellomrom for å byte. Escape avbryt.

Generelt → Teiknsett

Opne Teiknsett og slå på språka du skriv på. Hald minst eitt sett aktivt. Felles teikn vert berre viste éin gong.

Vel språket for grensesnittet under Generelt. Dette endrar ikkje dei aktive teiknsetta.

Lagre endringar tek i bruk innstillingane. Forkast endringar hentar tilbake den sist lagra konfigurasjonen. Pause verkar med ein gong.

Når du lukkar innstillingane, køyrer Accento vidare i varslingsområdet. Vel Avslutt i menyen for å stoppe programmet.

Microsoft Edge WebView2 Runtime er nødvendig. Grensesnittet verkar utan nett. Tastaturmotoren støttar førebels berre Windows.

Standardalfabetet og tilgjengelege tastetilordningar står nedanfor. Skriv vanlege bokstavar som normalt. Veljaren støttar òg digrafar og kombinerande teikn, men erstattar ikkje ein inndatametode.
