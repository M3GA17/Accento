# Rychlý start Accento — Čeština

> Tato přeložená příručka je koncept a nebyla zkontrolována rodilým mluvčím.

Otevřete Accento.exe v systému Windows. Rozhraní nastavení je vždy tmavé.

Podržte písmeno, stiskněte a uvolněte mezerník, poté uvolněte písmeno a vložte vybraný znak. Pro změnu použijte Left, Right nebo Space. Útěk se ruší.

Otevřete znakové sady a povolte jazyky, ve kterých píšete. Nechte aktivní alespoň jednu sadu. Sdílené postavy se objevují pouze jednou.

Vyberte jazyk rozhraní v Obecné. Tím se nezmění vaše aktivní znakové sady.

Save changes použije vaše nastavení. Zahodit změny obnoví poslední uloženou konfiguraci. Pauza se projeví okamžitě.

Zavření nastavení ponechá Accento spuštěný v oznamovací oblasti. Chcete-li jej zastavit, vyberte z nabídky Konec.

Je vyžadován Microsoft Edge WebView2 Runtime. Rozhraní funguje offline. Vstupní modul aktuálně podporuje pouze systém Windows.

Standardní abeceda a dostupné asociace klíčů jsou uvedeny níže. Pište běžná písmena normálně. Vyskakovací okno také podporuje digrafy a kombinování značek; nenahrazuje metodu zadávání.
