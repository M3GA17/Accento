# Accento sürətli başlanğıc — Azərbaycanca

> Bu tərcümə edilmiş bələdçi qaralamadır və ana dilində danışan şəxs tərəfindən nəzərdən keçirilməyib.

Windows-da Accento.exe-i açın. Parametrlər interfeysi həmişə qaranlıqdır.

Məktubu saxlayın, Boşluq düyməsini basın və buraxın, sonra seçilmiş simvolu daxil etmək üçün məktubu buraxın. Dəyişmək üçün Sol, Sağ və ya Boşluqdan istifadə edin. Escape ləğv edir.

Simvol dəstlərini açın və yazdığınız dilləri aktivləşdirin. Ən azı bir dəsti aktiv saxlayın. Paylaşılan simvollar yalnız bir dəfə görünür.

Ümumi olaraq interfeys dilini seçin. Bu, aktiv xarakter dəstlərinizi dəyişmir.

Dəyişiklikləri yadda saxla parametrlərinizi tətbiq edir. Dəyişiklikləri ləğv etmək son saxlanmış konfiqurasiyanı bərpa edir. Fasilə dərhal qüvvəyə minir.

Parametrlərin bağlanması Accento-ni bildiriş sahəsində işlək vəziyyətdə qoyur. Onu dayandırmaq üçün onun menyusundan Çıxış seçin.

Microsoft Edge WebView2 Runtime tələb olunur. İnterfeys oflayn işləyir. Daxiletmə mühərriki hazırda yalnız Windows-u dəstəkləyir.

Standart əlifba və mövcud əsas assosiasiyalar aşağıda verilmişdir. Normal hərfləri yazın. Açılan pəncərə həmçinin diqrafları və işarələri birləşdirməyi dəstəkləyir; daxiletmə metodunu əvəz etmir.
