# Accento სწრაფი დაწყება — ქართული

> ეს თარგმნილი გზამკვლევი არის მონახაზი და არ არის განხილული მშობლიური სპიკერის მიერ.

გახსენით Accento.exe Windows-ზე. პარამეტრების ინტერფეისი ყოველთვის ბნელია.

გეჭიროთ ასო, დააჭირეთ და გაათავისუფლეთ Space, შემდეგ გაათავისუფლეთ ასო არჩეული სიმბოლოს ჩასართავად. გამოიყენეთ მარცხენა, მარჯვენა ან ინტერვალი მის შესაცვლელად. გაქცევა უქმდება.

გახსენით სიმბოლოების ნაკრები და ჩართეთ ენები, რომლებშიც წერთ. შეინახეთ მინიმუმ ერთი ნაკრები აქტიური. გაზიარებული სიმბოლოები გამოჩნდება მხოლოდ ერთხელ.

აირჩიეთ ინტერფეისის ენა ზოგადად. ეს არ ცვლის თქვენს აქტიურ პერსონაჟთა კომპლექტს.

ცვლილებების შენახვა ეხება თქვენს პარამეტრებს. ცვლილებების გაუქმება აღადგენს ბოლო შენახულ კონფიგურაციას. პაუზა დაუყოვნებლივ მოქმედებს.

პარამეტრების დახურვის შემდეგ Accento მუშაობს შეტყობინებების ზონაში. მის შესაჩერებლად აირჩიეთ გასვლა მისი მენიუდან.

Microsoft Edge WebView2 Runtime საჭიროა. ინტერფეისი მუშაობს ოფლაინში. შეყვანის ძრავა ამჟამად მხარს უჭერს მხოლოდ Windows-ს.

სტანდარტული ანბანი და ხელმისაწვდომი საკვანძო ასოციაციები მოცემულია ქვემოთ. აკრიფეთ ჩვეულებრივი ასოები. ამომხტარი ასევე მხარს უჭერს დიგრაფებს და აერთიანებს ნიშნებს; ის არ ცვლის შეყვანის მეთოდს.
