# Accento quick start — English

> This translated guide is a draft and has not been reviewed by a native speaker.

Open Accento.exe on Windows. The settings interface is always dark.

Hold a letter, press and release Space, then release the letter to insert the selected character. Use Left, Right or Space to change it. Escape cancels.

General → Character sets

Open Character sets and enable the languages you write in. Keep at least one set active. Shared characters appear only once.

Choose the interface language in General. This does not change your active character sets.

Save changes applies your settings. Discard changes restores the last saved configuration. Pause takes effect immediately.

Closing settings leaves Accento running in the notification area. Choose Exit from its menu to stop it.

Microsoft Edge WebView2 Runtime is required. The interface works offline. The input engine currently supports Windows only.

The standard alphabet and available key associations are listed below. Type ordinary letters normally. The popup also supports digraphs and combining marks; it does not replace an input method.
