# Accento быстрый старт — Русский

> Это переведенное руководство является черновиком и не проверялось носителем языка.

Откройте Accento.exe в Windows. Интерфейс настроек всегда темный.

Удерживайте букву, нажмите и отпустите пробел, затем отпустите букву, чтобы вставить выбранный символ. Используйте «Влево», «Вправо» или «Пробел», чтобы изменить его. Побег отменяется.

Откройте наборы символов и включите языки, на которых вы пишете. Оставьте хотя бы один набор активным. Общие персонажи появляются только один раз.

Выберите общий язык интерфейса. Это не меняет ваши активные наборы символов.

При сохранении изменений применяются ваши настройки. Отменить изменения восстанавливает последнюю сохраненную конфигурацию. Пауза вступает в силу немедленно.

При закрытии настроек Accento остается запущенным в области уведомлений. Выберите «Выход» в меню, чтобы остановить его.

требуется среда выполнения Microsoft Edge WebView2. Интерфейс работает в автономном режиме. Механизм ввода в настоящее время поддерживает только Windows.

Ниже перечислены стандартный алфавит и доступные сочетания клавиш. Набирайте обычные буквы обычным способом. Всплывающее окно также поддерживает орграфы и комбинированные знаки; он не заменяет метод ввода.
