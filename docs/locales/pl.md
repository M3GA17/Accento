# Szybki start Accento — Polski

> Ten przetłumaczony przewodnik jest wersją roboczą i nie został sprawdzony przez native speakera.

Otwórz Accento.exe w systemie Windows. Interfejs ustawień jest zawsze ciemny.

Przytrzymaj literę, naciśnij i zwolnij spację, a następnie zwolnij literę, aby wstawić wybrany znak. Użyj lewej, prawej lub spacji, aby to zmienić. Ucieczka zostaje anulowana.

Ogólne → Zestawy znaków

Otwórz Zestawy znaków i włącz języki, w których piszesz. Przynajmniej jeden zestaw powinien być aktywny. Udostępnione znaki pojawiają się tylko raz.

Wybierz ogólnie język interfejsu. Nie zmienia to aktywnych zestawów znaków.

Zapisz zmiany stosuje Twoje ustawienia. Odrzuć zmiany przywraca ostatnią zapisaną konfigurację. Pauza zaczyna obowiązywać natychmiast.

Zamknięcie ustawień powoduje, że Accento działa w obszarze powiadomień. Wybierz z menu opcję Exit, aby ją zatrzymać.

Wymagane jest środowisko wykonawcze Microsoft Edge WebView2. Interfejs działa w trybie offline. Mechanizm wejściowy obsługuje obecnie tylko system Windows.

Poniżej wymieniono standardowy alfabet i dostępne powiązania klawiszy. Wpisz normalnie zwykłe litery. Wyskakujące okienko obsługuje także dwuznaki i znaki łączące; nie zastępuje metody wprowadzania.
