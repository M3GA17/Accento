# Accento 0.5.0-beta.1

**Local draft — not published. Windows x64 only.**

Accento brings accents and character variants to the app where you are already typing. Hold a letter, tap Space, choose a glass key and release the letter to insert it.

## In this beta

- Native floating glass keys, a shared accented-a glass logo and dark React/Tauri settings.
- 47 language entries and written variants, with independently selectable character sets and interface language.
- Searchable sets, supported digraphs and combining marks, and uppercase variants.
- Configurable opening delay, application exclusions, notification-area pause/resume and draft-safe settings.
- A Windows installer for the current user and a portable ZIP, including documentation, localized guides, licenses and SHA-256 checksums.

## Packages

| File | Purpose |
| --- | --- |
| `Accento_0.5.0-beta.1_windows-x64-setup.exe` | Windows installer; downloads WebView2 if it is missing |
| `Accento_0.5.0-beta.1_windows-x64_portable.zip` | Extract all files and run `Accento.exe`; needs an existing WebView2 runtime |
| `SHA256SUMS.txt` | SHA-256 checksums for both files |

Requires Windows 11 x64 on Intel/AMD hardware. Binaries are unsigned; no automatic updater is included. App operation is offline after prerequisites are installed. Preferences are stored in `%LOCALAPPDATA%\Accento\settings.json`.

## Known limits

Linux and macOS native integrations are not implemented. Translations are drafts awaiting native-speaker review. Elevated apps, complex IMEs, remote sessions, protected fields and individual keyboard layouts require additional testing; see the [usage guide](../../docs/uso.md) for the supported gesture and detailed limits. Pause other accent tools using the same shortcut while trying the beta.

The number 0.5.0-beta.1 starts public beta numbering; references to 0.6.0 in earlier internal verification reports are development history.
