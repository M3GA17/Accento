# Accento 0.5.0-beta.2

Windows x64 prerelease. Downloads require access to the private M3GA17/Accento repository.

Hold a letter, tap Space, choose a glass key and release the letter to insert an accent or character variant.

## Changes

- General settings now include the character-set panel, with responsive columns, search, keyboard-accessible disclosure and bulk selection.
- The Currency special set is enabled by default, independently of language selection. For example, `e` offers `€` after the Italian accents; `s`, `l` and `y` offer `$`, `£` and `¥`. Expand Currency to inspect the key mappings. Shift and Caps Lock preserve currency symbols.
- Settings components, styles and theme are maintained inside Accento. The DimaLabs package archives and checkout dependencies have been removed; React Aria supplies accessible interactions.
- Updated translations and all 47 localized quick-start guides, with currency instructions and screenshot regression coverage.
- Shared gesture and preferences logic supports the Windows, Linux X11 and macOS source backends. This release distributes Windows binaries only.

## Downloads

| File | Purpose |
| --- | --- |
| `Accento_0.5.0-beta.2_windows-x64-setup.exe` | Current-user Windows installer; can download WebView2 if missing |
| `Accento_0.5.0-beta.2_windows-x64_portable.zip` | Extract the entire archive and run `Accento.exe`; requires WebView2 |
| `SHA256SUMS.txt` | SHA-256 checksums for both packages |

Requires Windows 11 x64 on Intel/AMD hardware. Both packages include documentation, 47 localized guides and dependency licenses. Preferences remain in `%LOCALAPPDATA%/Accento/settings.json`. Accento works offline after prerequisites are installed.

## Verification and limits

See the [beta 2 verification report](https://github.com/M3GA17/Accento/blob/v0.5.0-beta.2/docs/verifiche-0.5.0-beta.2.md) for build checks and package hashes.

The beta is unsigned and has no automatic updater. Clean-machine installation and WebView2 bootstrap installation still need dedicated verification. Translations await native-speaker review. Elevated applications, complex IMEs, remote sessions, protected fields and individual keyboard layouts require further testing. Pause other accent tools using the same gesture.

Linux X11 has earlier local build and isolated input checks; macOS has earlier backend type checks for Intel and Apple Silicon, but a complete app build and live permission/input tests still need a Mac. No Linux or macOS packages are attached. Native Wayland input is not implemented. See the [platform scope](https://github.com/M3GA17/Accento/blob/v0.5.0-beta.2/docs/cross-platform.md).
