# Accento 0.5.0-beta.3

Windows x64 and universal macOS prerelease, intended for testing before stable 0.5.0. Downloads require access to the private M3GA17/Accento repository. Linux X11 and Wayland are deferred to a later release.

## Changes

- First distributed Mac beta for both Intel and Apple Silicon, with native Quartz input and a transparent picker.
- A manually dispatched Mac build workflow checks the universal app, bundle signature, documentation, native WebView startup, Rust IPC and isolated settings persistence. The same packaged app is checked on Apple Silicon and Intel runners with keyboard hooks disabled.
- `--diagnostics` prints version and architecture; on Mac it also reports Accessibility, Input Monitoring, event-posting access and Secure Event Input status, without starting input hooks or reading document contents.
- Included Italian Mac setup/test checklist and feedback format.
- Visual regression captures wait for the logo to load before comparing screenshots.

## Downloads

| File | Purpose |
| --- | --- |
| `Accento_0.5.0-beta.3_windows-x64-setup.exe` | Current-user Windows installer; can download WebView2 if missing |
| `Accento_0.5.0-beta.3_windows-x64_portable.zip` | Extract all files and run `Accento.exe`; requires WebView2 |
| Universal macOS DMG | Drag `Accento.app` into Applications |
| `Accento_0.5.0-beta.3_universal_macos.zip` | Alternative universal app archive; extract and move the app into Applications |
| `SHA256SUMS.txt` | Checksums for all four packages |
| `TEST-MACOS.it.txt` | Setup steps, test scenarios and feedback form for the Mac tester |
| `macos-verification-arm64.json`, `macos-verification-intel.json` | Native package/startup checks; these do not certify live input |

Windows requires Windows 11 x64 on Intel/AMD hardware. macOS requires macOS 13 or newer; the configured minimum still needs testing. Both platforms include documentation, 47 localized quick-start guides and dependency licenses. Accento works offline after prerequisites are installed and has no automatic updater.

## Mac test cycle

The Mac beta uses an **ad-hoc signature** and is **not notarized**. Apple has not verified the publisher. After moving it into Applications, follow [Apple's Open Anyway procedure](https://support.apple.com/en-us/102445) if the trusted download is blocked. Grant Accessibility and, if requested, Input Monitoring permission. Quit/reopen the installed app when required, then turn Accento on.

Follow the [included test checklist](https://github.com/M3GA17/Accento/blob/v0.5.0-beta.3/docs/distribution/TEST-MACOS.it.txt) in TextEdit, browsers and the applications you use. Report the Mac processor, macOS and keyboard layout, target app, exact gesture, permission state and observed result. Native build/startup checks keep hooks disabled; live typing, focus behavior, permission recovery, protected fields and accessibility await tester feedback. The feedback and any resulting fixes precede stable 0.5.0.

Windows binaries remain unsigned. Clean-machine installation, application/layout coverage, IMEs, remote sessions and full accessibility checks have the existing beta limits. New translations await native-speaker review. See [the platform scope](https://github.com/M3GA17/Accento/blob/v0.5.0-beta.3/docs/cross-platform.md).
