# README artwork

`settings.png`, `character-sets.png` and `compact.png` are captured by `scripts/capture-docs.mjs` from the embedded Windows release UI, using a temporary English profile and no keyboard hook.

`picker-source.png` is the 152 × 80 transparent native rendering fixture originally produced by the 0.4.0 Windows self-test (`docs/evidenze/0.4.0/picker-dark-alpha.png`). It shows the same native glass material used by the current picker. It is saved here so documentation can be regenerated without rerunning synthetic typing tests or depending on untracked evidence directories. Any lettering visible within the frosted keys is part of the controlled fixture background.

`hero.png` and `picker.png` arrange these captures on documentation backgrounds. The picker fixture is displayed at twice its capture dimensions; the documentation composition is not an additional app screen.

`logo.svg` comes from the shared original vector mark. `badges.svg` and the cover are produced by the same capture script. No personal desktop, clipboard contents or external image assets are used.
